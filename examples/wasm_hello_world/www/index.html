🎮 关于此 Demo

  • 框架：AutoZig-Bevy ECS（Zig + Rust 混合）
  • 架构：App + System 模式
  • 目标：WASM64 (Memory64)
  • 系统数量：5 个闭包系统

📋 系统列表

  • System 1: 输出 Hello World 消息
  • System 2: 显示使用的框架名称
  • System 3: 执行计数器（演示状态管理）
  • System 4: 模拟游戏状态更新
  • System 5: 模拟渲染管线

🔒 安全约束

  • ✅ 所有 Zig 函数立即使用并返回
  • ✅ 不保存 raw pointer 到 Rust struct
  • ✅ 同步执行，无 spawn
  • ✅ 避免跨 FFI 边界的复杂数据结构
